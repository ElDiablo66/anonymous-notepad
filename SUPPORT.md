# Getting help

- Something broken: open a [bug report](https://github.com/ElDiablo66/anonymous-notepad/issues/new?template=bug_report.yml). Say which version you run (Tools, About) and how to make it happen again.
- An idea or a missing feature: open a [feature request](https://github.com/ElDiablo66/anonymous-notepad/issues/new?template=feature_request.yml). Check the [roadmap](docs/roadmap.md) first, it may already be planned.
- A question about how something works: the [README](README.md) covers install, keys, data files and known limits. If it doesn't answer you, open an issue and say it's a question.
- A security problem: follow [SECURITY.md](SECURITY.md) instead, so it stays private.

Your tabs and preferences live in `%APPDATA%\app.anonymousnotepad.desktop\`. If the app won't start after an update, renaming that folder starts it clean without losing the old files.

This is a one-person project, so replies can take a few days.
